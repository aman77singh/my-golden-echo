# Romantic Relationship Portfolio

## Experience
- Build one cinematic scrolling page with a fixed desktop sidebar, mobile menu, smooth section navigation, visited-state tracking, and the locked bonus reveal.
- Use a deep near-black palette with warm gold and rose accents, serif/script typography, vignette lighting, glow, and a subtle film-grain layer.
- Add a short skippable initials-to-heart intro, heart cursor trail, reduced-motion support, and restrained Framer Motion transitions.

## Sections
- **Home / Us:** names, tagline, generated couple photograph, live relationship counter, milestone burst, constellation canvas, and scroll cue.
- **Our Timeline:** the six supplied moments in alternating cards with a scroll-filled luminous timeline.
- **Photo Dump:** twenty cohesive generated photo memories in a responsive masonry composition with gentle parallax, captions, and a full-screen lightbox.
- **My Apologies:** four supplied notes as tactile scratch-to-reveal canvases with handwritten styling.
- **Random Thoughts:** five supplied entries in an organic scrapbook composition with polaroids and small doodles.
- **Music:** persistent vinyl player, animated notes, playlist drawer, configurable Spotify playback/embed fallback, and warmer “our song” accent state.
- **A Letter To You:** an editable original sample letter revealed line-by-line, dated automatically, with a heartbeat close.
- **Bonus:** unlock after every required section has been visited, shimmer the navigation item, then reveal a final image, message, and editable future-date countdown.

## Editable Content
- Put names, dates, all copy, photo paths/captions, timeline entries, apologies, thoughts, letter lines, Spotify IDs, playlist tracks, “our song,” and bonus date in one clearly documented content file.
- Use tasteful sample names and dates so the first preview is complete; every invented personal detail remains visibly easy to replace in that file.

## Technical Details
- Add Motion for React for transitions and scroll effects, while keeping canvas work isolated for stars and scratch cards.
- Keep Spotify credentials out of source: the content file accepts the public client and playlist IDs, with a polished demo/fallback state until real values are supplied.
- Split the page into focused components, lazy-load images, keep desktop/mobile layouts stable, and provide keyboard-accessible navigation, drawer, and lightbox.
- Add unique home-page metadata and replace all template branding.

## Validation
- Check current diagnostics after implementation.
- Verify desktop and mobile layouts, navigation, section tracking/unlock, scratch interaction, player drawer, and lightbox in the live preview.
